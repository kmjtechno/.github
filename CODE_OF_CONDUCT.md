# Community Code of Conduct

KMJ TECHNO projects welcome focused, constructive technical collaboration.

Contributors and maintainers are expected to communicate respectfully, critique work rather than individuals, explain technical decisions with evidence, respect others' time and privacy, and follow repository security and authorization boundaries.

Harassment, personal attacks, discriminatory abuse, spam, intentional disruption, doxxing, unauthorized access and disclosure of private or customer information are not acceptable.

Maintainers may edit or remove inappropriate content, request changes, close discussions, or restrict participation to protect project safety. If a community conduct concern arises, contact the maintainers through an appropriate **private** project channel; do not expose personal details in public issues.

This policy applies to repository discussions, pull requests, code review and related KMJ TECHNO community spaces. Repository-specific rules may add stronger requirements.
